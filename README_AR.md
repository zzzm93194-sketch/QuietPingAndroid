# تطبيق QuietPing لنظام Android

هذا مشروع Android Studio يحوّل موقع QuietPing إلى تطبيق يفتح داخل نافذة تطبيق مستقلة باستخدام WebView.

## بناء ملف APK

1. نزّل وثبّت Android Studio على الكمبيوتر.
2. فك ضغط `QuietPingAndroid.zip`.
3. من Android Studio اختر **Open** وحدد مجلد `QuietPingAndroid`.
4. انتظر اكتمال Gradle Sync، واسمح بتنزيل مكونات Android SDK إذا طُلب ذلك.
5. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. بعد نجاح البناء اضغط **locate** في إشعار Android Studio. ستجد الملف عادةً هنا:
   `app/build/outputs/apk/debug/app-debug.apk`
7. انقل APK إلى هاتف Android وثبّته.

## ملاحظات
- التطبيق يحتاج اتصال إنترنت لأن محتوى الموقع يُحمّل مباشرة من الرابط.
- أضفت زر/رسالة إعادة المحاولة عند تعذر تحميل الصفحة، ودعم زر الرجوع داخل الموقع.
- الروابط الخارجية تفتح في المتصفح.
- لم أتمكن من اختبار كل وظائف الموقع من بيئة البناء؛ لذلك يلزم تجربة تسجيل الدخول والإشعارات وأي ميزات تعتمد على صلاحيات الجهاز بعد التثبيت.
- هذا الأرشيف يحتوي مشروع Android Studio المصدري، وليس ملف APK مبنياً. يلزم Android Studio وAndroid SDK لإنتاج APK.

## بناء APK تلقائياً عبر GitHub (بدون تثبيت Android Studio)

1. أنشئ مستودعاً جديداً على GitHub وارفع إليه محتويات هذا المجلد.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build QuietPing APK** ثم **Run workflow**.
4. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
5. نزّل `QuietPing-APK.zip`؛ بداخله ملف `app-debug.apk` الجاهز للتثبيت على Android.

هذه الطريقة تبني نسخة Debug للتجربة. لا تشارك مفاتيح توقيع أو كلمات مرور داخل المستودع.
